# 项目总览索引决策记录

## 记录时间

2026-06-09

## 背景

在 NovAI 的小说创作流程里，曾考虑为每个小说项目增加一个独立的项目总览索引文件，用来汇总：

- 当前写到哪一章
- 已有哪些人物、地点、剧情块、时间线
- 哪些伏笔还没回收
- 最近更新了什么

这个想法的作用类似于 Claude Code 的 `CLAUDE.md`，但更偏向“项目状态地图”。

## 结论

当前阶段**暂不单独实现**该索引文件。

原因是项目刚起步，基础能力还不齐全，优先级应放在更直接影响创作和落地的功能上，而不是先补一个状态汇总层。

## 当前约定

- `system.md` 继续承担“怎么写”的职责，放稳定的创作规则、文风、视角和约束。
- 项目总览索引先不做，等后续功能更完整、内容更多时再补。
- 现阶段优先推进更关键的能力，例如：
  - 章节创作与修改
  - 人物、地点、剧情、时间线等要素管理
  - 文件检索与回写
  - 语义检索与上下文召回

## 备注

这份记录只用于保留当前决策，后续如果项目规模扩大，再重新评估是否新增 `NovAI.md` 作为项目状态索引。
