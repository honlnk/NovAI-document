# 现有工作区交互体验优化计划

## 文档状态

- 记录日期：2026-11-07。
- 当前状态：**整体重设计方案已中止，交互优化范围待用户确认后重新开工**。
- 原计划中的页面规格样张、浅色导航、暖中性配色和全产品信息架构重组全部停止作为施工依据；不得据此修改应用。
- 本计划保留现有 UI 整体架构，仅处理已核实的交互缺陷、确认与反馈、状态恢复、图标及必要的局部可读性。每阶段必须完成测试、类型检查、文档同步和真实浏览器验收后才算完成。
- 本计划不自动批准共享文件修改、代码提交或推送。实际施工遵循仓库许可与提交规则。

## 一、目标与不可逾越的边界

目标不是重做 NovAI，而是让用户在**现有工作台**里写小说时少被打断、看得懂 AI 做了什么、正常操作不会被误报为失败、离开再回来能继续原来的工作。

### 必须保持不变

| 现有部分 | 本计划的约束 |
| :-- | :-- |
| 整体页面骨架 | 保留首页、分类导航、中央对话或计划区、右侧内容面板、底部状态区及现有路由，不重新编排页面 |
| 视觉体系 | 保留当前深色工作台、配色、字体、字号体系、边框与阴影风格，不建立另一套视觉主题 |
| 功能入口 | 保留现有分类、设置入口、索引入口和其他导航，不迁移、合并或删除功能入口 |
| 面板与稿件布局 | 保留当前面板宽度、展开方式、阅读与编辑模式和正文排版；只在现有区域增加字数、保存状态与修改反馈 |
| 设置与索引 | 保留现有分组和配置项顺序，只修正保存状态、失败反馈及必要说明，不重做设置信息架构 |
| 内核行为 | 不改变 Agent 权限、模型协议、检索算法、任务语义和小说项目文件格式 |
| 用户内容 | 不转换正文、聊天、Markdown、文件名和计划内容中的 Emoji 或其他字符 |

### 允许的局部变化

1. 替换已经确认不合理的确认卡、提示样式、会话列表项和图标，但不改变所属页面及整体布局。
2. 内容创建与编辑确认进入**现有右侧内容面板**；非编辑请求按用户已确认的方式在**现有输入卡片位置**接管。
3. 在现有稿件预览中定位真实修改并显示红绿差异；不引入新的正文编辑器或稿件工作流。
4. 保存现有分类、会话、文件和面板状态，修复刷新后跳回默认位置。
5. 修复发送残行、命令长文本、目录取消误报、计划拖拽抖动等已明确的问题。

任何施工内容若需要改变上表中的“必须保持不变”，必须停止并重新征求用户确认，不能以“体验升级”为由自行扩大范围。

## 二、调研事实与未确诊事项

### 已核实

- 现有变更账本保存修改片段，但缺少可靠的逐处修改坐标和文件版本；自动定位需要补充服务层信息，不能由界面搜索重复文本猜位置。
- 分类固定以章节初始化，项目恢复会主动打开首个文件，会话初始化会选最近一项，缺少跨刷新的工作区恢复记录。
- 会话删除使用原生确认并直接永久删除；普通斜杠命令在发送前被展开为内部提示词，气泡、队列、历史和自动标题因此获得全文。
- 界面六类要素使用 Emoji，其他区域也有 Emoji、字符图形及约 93 处散落在 31 个组件中的手写 SVG，没有统一图标组件。
- 计划拖拽已在隔离副本中复现：提示“正在同步计划…”高 29px，看板顶部 57→86→57px、高度 635→606→635px，约 12ms 后恢复，6 张卡片始终存在。根因是提示条插入正常文档流后移除，不是卡片消失。
- 首页目录选择器取消被统一当成项目失败，首页固定红底错误区将其放大。打开和新建时取消都存在该问题。
- 上次计划加载修复解决了后台刷新清空看板和首载外骨架闪现，没有约束提示条造成的几何位移。
- 单行真实键盘发送未复现额外空行；不能把未经复现的发送链写成已经通过，也不能预设根因。

### 尚未验证

- 中文输入法、多行发送、屏幕阅读器和真实鼠标设备拖拽尚未完成真人验证。
- 真实模型触发的写入确认、主动提问和流式回复尚未完成本轮视觉验收。
- 页面内原生拖拽事件已成功复现计划问题；坐标式鼠标拖拽未生效，截图超时，证据来自 DOM 与约 10ms 几何采样。

## 三、局部交互设计

### 1. 输入、命令与普通对话

- 保留现有 Lexical 编辑器、引用、补全、大纲、排队、插话和历史能力。Enter 发送、Shift+Enter 换行、Ctrl/Cmd+Enter 插话，输入法组字时不抢键。
- 先通过浏览器事件与编辑器状态定位发送残行，再修根因；不能通过破坏换行、补全或命令菜单规避。
- 发送或入队成功才清空对应草稿，失败保留用户原文。普通聊天输入仍留在原位置，权限、思考强度、发送和停止的位置不变。
- 用户消息、回复、工具过程和变更摘要保持现有结构，只修复命令状态与明显的状态表达缺失，不重新设计消息流。

### 2. 斜杠命令：显示命令，不显示内部任务全文

保留提示词命令与本地命令的现有语义，借鉴 DeepSeek Harness 的紧凑指令状态，但不重做命令菜单或输入区。

| 场景 | 固定行为 |
| :-- | :-- |
| 提示词命令 | 用户气泡和队列显示原命令及参数；模型仍收到完整任务。命令身份、原始输入和模型指令保持对应 |
| 排队、插话、编辑与重试 | 以用户看到的命令草稿为显示真值，重新生成对应模型指令，不发生错配 |
| 自动标题 | 使用命令名和必要参数，不使用内部提示词全文 |
| 本地命令 | 以图标、命令名和“排队中 / 执行中 / 已完成 / 未执行 / 失败”紧凑状态行持续反馈，不插入大段内部文本 |
| 非法命令或参数 | 在输入区附近说明原因并保留草稿，不静默退化为普通长提示 |
| 多行结果 | 点击状态行展开，展开区内部滚动；错误详情可复制，但不展示无意义的异常堆栈 |

本地命令独立防重复，区分“完成”与“没有可处理内容，未做修改”。旧会话缺少命令身份时保持原文，不猜测、不批量迁移。

### 3. 会话列表、归档与撤销

保留会话列表在现有分类侧栏中的位置，只调整列表项和操作：

- 默认按最近实际活动排序，角色用小标签区分，不再按角色拆成多个大组。保留“新对话”，提供标题搜索和“全部 / 进行中 / 待处理 / 已归档”筛选。
- 列表项显示标题、相对时间和真实状态；重命名、归档收进每项“更多”菜单，菜单在悬停、键盘聚焦和触屏均可达。
- 后台会话的活动、完成和失败更新摘要与排序，但不自动切换当前会话。
- 原“删除对话”改为**归档**。归档不弹确认、不停止模型、委派、队列或等待请求，只改变默认列表可见性。
- 归档当前会话后切到最近的未归档会话，没有则新建空会话；归档其他会话不改变当前现场。
- 成功后提示“已归档「会话名」”，提供“撤销”和“查看已归档”。快捷撤销入口保留 5 秒，再以约 200ms 淡出；长期恢复由归档区承担。
- 连续归档各自保留撤销能力；撤销不抢占用户后来切到的会话。只有永久删除需要危险确认。
- 会话增加可选归档时间，旧会话缺字段视为未归档。归档与恢复不改变原活动时间，后台保存不得抹掉归档字段。

### 4. 工作区现场恢复

按项目在浏览器中保存上次分类、会话、文件、分类侧栏和内容/计划面板展开状态及已有面板宽度。刷新、正常关闭重开和从首页恢复项目时恢复，不写入小说项目或模型上下文。

- 项目打开后先恢复现场，再接受新选择；初始化不得先把默认章节、首文件或最近会话写回记录。
- 区分“尚无恢复记录”和“用户明确没有选择文件”；后者不能再次自动打开首文件。
- 保存对象不存在、已归档或读取失败时保留原分类，文件回退为空选择，会话回退到最近未归档会话，并显示可恢复提示。
- 快速切换使用项目与请求代次保护，晚到响应不能覆盖新选择，不同项目不串现场。
- 本项只恢复工作区现场，不顺带建立跨刷新的正文自动保存或另一套聊天草稿系统。发送失败仍保留聊天原文；正文未保存内容遵循第六节的保护规则。

### 5. 提示、弹层与取消操作

提示按结果性质分级：**主动取消或无变化不是错误；需要用户补充操作的非破坏性中断用黄色提醒；真实失败才用红色错误。** 就地反馈优先，Toast 只承担没有明确现场的轻量结果。

| 操作 | 局部反馈 | 固定规则 |
| :-- | :-- | :-- |
| 打开或新建项目时取消目录选择 | 原操作附近的黄色轻提醒 | 分别提示“未选择目录，项目未打开 / 未创建”，3 秒后以约 200ms 淡出；保留页面现场，不写项目记录，不用红色或失败文案 |
| 恢复项目时拒绝授权 | 黄色授权提醒 | 说明项目尚未打开，提供重新授权；不得把所有权限拒绝误识别为取消 |
| 文件读取、保存、冲突与刷新 | 现有内容面板或文件列表 | 真实成功才报已更新；失败保留现场、原因和重试，不覆盖未保存内容 |
| 会话归档 | 可撤销轻提示 | 5 秒撤销；连续提示互不取消，不遮挡发送与停止 |
| 命令、队列、停止 | 现有输入区、命令行或队列行 | 区分排队、执行、无变化、失败；提交中防重复，失败保留原文 |
| 设置与索引 | 现有设置分组或索引管理区域 | 区分待保存、保存中与失败；无真实进度不伪造百分比 |
| 全局轻量结果 | 统一轻提示 | 成功与信息默认 3 秒；普通错误保留到关闭或进入对应现场 |

- 黄色提醒使用低饱和黄色细边框、浅底与警告图标，不使用整页或大卡片染黄。它不改变主要内容位置、不抢焦点，再次执行原操作时关闭同类旧提醒。
- 一般轻提示使用克制的浮层样式，桌面不遮挡主要操作，窄屏留出安全边距；提示可键盘关闭，状态与错误使用合适的辅助技术语义。
- 原生确认框退出普通交互：归档不确认；永久删除保留危险确认；Agent 的删除、重命名请求使用第八节的底部接管。
- 对话框与菜单补齐 Escape、焦点恢复、防重复提交和长名称处理，但不统一重写现有页面布局。

### 6. 稿件字数、保存与未保存内容保护

保留当前右侧内容面板、正文排版、预览和纯文本编辑模式，只补充信息与保护：

- 在现有稿件头部或次级信息区显示“正文 1,234 字”和“已保存 / 未保存 / 正在保存 / 保存失败”，不调整面板默认宽度或改为另一套阅读器。
- `.txt` 章节只有首行符合既有“第 + 编号 + 章 + 空白 + 标题”约定时排除标题；统计正文非空白字符，包含标点，空文件为 0。
- Markdown 使用解析后的纯文本统计非空白字符，排除标记、链接地址、元信息头和代码语言标记，普通文字与实际代码内容计入。
- 字数统计当前阅读版本，包括未保存编辑内容；保存必须等待真实写盘，失败保留草稿、编辑位置和重试。
- 切换预览/编辑、文件、分类或收起面板不得静默丢失未保存内容。至少沿用现有编辑会话保留机制，并在真实离开或刷新风险存在时提供保存、放弃或继续编辑的明确选择。
- AI 或外部修改不得覆盖人工未保存内容。已有版本冲突与恢复能力继续保留；缺少可靠保护时先补版本校验，不能为了高亮强行覆盖。

### 7. 自动编辑后的定位、差异与淡出

免确认的新建和正文编辑成功后，以实际变更为触发，在**当前内容面板**中反馈：

1. 定位首个真实修改位置；新内容绿色、被替换或删除的原文以相邻红色差异呈现，删除文字只用于比较，不写回磁盘。
2. 首次定位后稳定显示约 2.5 秒，再以约 1.2 秒淡出；之后保留“重新查看本轮差异”，重播历史记录时不自动播放。
3. 多处修改逐处呈现并可切换；不同文件形成反馈队列，不互相覆盖。
4. 用户正在编辑、有未保存内容、阅读另一文件或位于计划表面时，不强行跳转，只显示可点击的变更通知。
5. 后台会话的修改不抢占当前会话或分类；减少动态效果时取消平滑滚动与淡出，显示稳定差异。

为支持真实定位，服务层只为现有变更记录补充必要信息：会话与调用身份、目标路径、前后内容版本、逐处原范围与新范围、实际写入结果。界面不自行搜索文本猜位置，也不绕过服务层执行工具。

- 旧变更记录缺少坐标时仍显示现有片段差异，并说明“此历史记录不支持定位”，不伪造高亮或批量迁移。
- 纯文本按统一源码范围处理换行；Markdown 使用同版本源码到渲染块的映射，无法精确到块内时只定位完整块并展示原码差异。
- 版本失配、文件改名或坐标无效时降级为片段提示，绝不覆盖较新的内容。
- 计划文件只刷新现有计划工作流，不套用章节高亮。

### 8. 内容确认与非编辑请求的分流

#### 内容创建与编辑

新建和正文编辑确认进入**现有右侧内容面板**，不再使用聊天中的黄色截断双块卡：

- 顶部说明谁请求、修改哪个文件、当前第几项；底部固定提供“同意写入”和“拒绝”。
- 全文只读展示局部红绿差异与足够上下文，多处修改可跳转；新建文件展示完整候选内容，同意前不能伪装成已保存。
- 聊天区只保留“等待你审阅某稿件”和返回入口，不重复显示完整确认卡。
- 用户正在编辑、有未保存内容、位于计划或后台会话时，不自动抢现场；保留待审阅标记，点击后进入。
- 目标文件有人工未保存内容时，人工内容与 AI 候选分开查看。未经明确选择并安全保留人工内容，不得写入。
- 确认前重新校验版本，失配则暂停并展示新版本与候选差异；拒绝不写入，接受以真实工具结果刷新。
- 同会话逐项处理，跨会话不自动跳转。离开不取消请求，停止运行后服务层收敛等待状态。

#### 提问、重命名与删除

采用用户已确认的 DeepSeek Harness 式**输入区接管**，仅在原输入卡片位置替换当前交互，不改变页面架构：

- 普通编辑器保持挂载但暂时隐藏，草稿保留；队列、停止和会话切换仍可用。
- 使用紧凑、中性面板、细分隔线、内部滚动和固定底部操作，不用大面积黄色或蓝色卡片。
- 提问展示选项和独立补充说明；重命名展示原名、目标名与影响；删除明确回收站或永久删除的后果。
- 无编辑焦点时 Enter 允许一次、Escape 拒绝；输入控件、输入法、按钮原生键盘行为和修饰键优先。
- 每个请求独立锁定提交，失败保留选择与错误；多项请求逐项处理，不提供“一键全部允许”。
- 提问回答按会话与问题隔离，普通输入不再隐式把 Ctrl/Cmd+Enter 当成答案；已结束问题保留只读记录。

### 9. 图标统一

在现有图标位置使用本地 Lucide Vue 线性 SVG，通过受控语义组件按名称显式引入实际图形。品牌与 GitHub 保留专用 SVG，不运行时远程加载、不拼接任意 SVG 字符串、不全量注册图标库。共享组件和应用依赖施工前列入许可清单。

- 六分类固定为：人物轮廓、地图标记、菱形、日历、分支、地球。顺序、数量、折叠与目录归属不变。
- 收敛其他界面 Emoji、字符模拟图形和重复手写 SVG，但保留现有图标尺寸、控件位置和文本换行，不因此重排导航或页面。
- 装饰图标不重复朗读，纯图标按钮有可读名称，展开控件暴露状态；修复嵌套按钮等局部可访问性问题。
- 快捷键、增删计数和路径方向等文本不机械图标化；用户内容完全不转换。

### 10. 计划拖拽与同步反馈

保留当前看板、列、卡片、拖拽和冲突保护，不重写拖拽交互模型。
