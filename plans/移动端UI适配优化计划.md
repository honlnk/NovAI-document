4. 触屏上每个操作都够得着、看得懂：悬停才出现的按钮直接显示；图标说明「重要的写出来，其余长按查看」；触点达标。
5. 左侧工具栏保留竖条，图标下补文字标签。
6. 手机键盘回车是换行；发送、排队、插话用按钮。
7. 弹窗不出屏幕、背景不串滚；高度按动态视口算；页面按安全区与软键盘正确布局。

## 适用范围与约定

- **窄屏**：视口宽小于 640px，对应样式前缀 `max-sm:`。只在窄屏生效，桌面不变。
- **触屏**：主输入设备是触摸，对应样式前缀 `pointer-coarse:`（项目所用 Tailwind 4.3.0 自带，此前未用过）。悬停相关的兜底沿用各模块已有断点：分类列表用 `max-lg:`，首页用 `pointer-coarse:`。
- 回车换行需要脚本判断，用媒体查询 `(pointer: coarse)`，与上面的样式前缀同源，见 1.1。
- 桌面（鼠标、宽度不小于 640px）的外观与交互不变。唯二例外是静态视口高度改动态视口高度、弹窗外壳的限高与内边距——桌面同样受益，且没有可见差异。
- 本文路径均相对 `packages/app/src/`，另有说明的除外。

## 方案

### 1. 聊天输入区

**1.1 手机键盘回车换行**（`components/layout/ChatPanel.vue`、`composables/keyboard.ts`、`constants/agent-roles.ts`）

- 主输入设备为触摸时，对话输入框里的回车一律交给编辑器换行，不再触发发送或排队。
- 斜杠命令菜单、`@` 大纲弹层、`#` 技能弹层打开时同样换行：触屏上这些菜单用点按选择，方向键加回车是键盘操作，软键盘弹出时回车仍是用户的换行键。
- `Ctrl/Cmd+Enter` 保持插话不变，外接键盘照常可用。输入法组合中的回车维持现状：只拦掉默认行为，不换行。
- 发送、排队发送、插话、停止仍由工具行按钮触发。
- 编辑器宿主加 `enterkeyhint="enter"`，让软键盘的回车键显示成换行样式。
- 判定集中在一处：`composables/keyboard.ts` 新增一个只读判定函数，内部读 `(pointer: coarse)` 媒体查询；按键解析函数增加触屏参数。测试通过参数注入，不依赖运行环境。
- 单行输入框（搜索、设置表单、排队栏的行内编辑）不在此列，回车提交是它们的常规行为。

**1.2 智能体提问接管面板**（`components/chat/QuestionTakeover.vue`）

- 面板限高为视口的 60%（动态视口高度），内部纵向排列：标题与底部按钮固定，中间的问题说明、选项、补充文本框在面板内滚动。面板取代输入卡片出现，限高后至少给消息区留下三分之一屏幕。
- 底部提示只在「非窄屏且非触屏」显示（内容是键盘操作说明，见 1.5）；右侧按钮组独占一行，按钮文字不折行。
- 实现只用样式，不走脚本量高。

**1.3 重命名／删除确认面板**（`components/chat/WriteActionTakeover.vue`）

- 窄屏上下堆叠：说明文字占满整行，按钮组落到下方靠右。宽屏保持现在的左右排列，但文字列设最小宽度，不再被压成竖条。
- 面板同样限高为视口的 60%，内容内滚（重命名会列出长路径）。
- 键盘提示按 1.5 的规则隐藏；回车同意、Escape 拒绝的键盘行为保留——它只在外接键盘、焦点不在按钮上时触发。

**1.4 排队栏**（`components/chat/QueueDock.vue`）

- 窄屏下消息文字直接换行显示，最多 3 行，超出省略，不再单行截断。
- 行内「编辑／删除／立即插话」在触屏上视觉高度 32px、所在行高 44px；按钮文字不折行。
- 标签字号按第 3 节提到 12px。

**1.5 文案按输入方式切换**

输入区文案集中到一个小模块（新增 `constants/composer-copy.ts`），按「空闲／运行中」与「鼠标键盘／触屏」四种组合给出，组件不再散写。

| 位置 | 鼠标键盘（现状，不变） | 触屏 |
| :-- | :-- | :-- |
| 输入占位（空闲） | 输入创作指令... (Enter 发送，Shift+Enter 换行；输入 @ 切换大纲) | 输入创作指令...（输入 @ 切换大纲） |
| 输入占位（运行中） | Agent 运行中：Enter 排队发送，Ctrl/Cmd+Enter 插话，Shift+Enter 换行 | Agent 运行中：发送的消息会排队，点「插话」可在下一步前插入 |
| 要素管理员占位（`constants/agent-roles.ts`） | 向要素管理员描述任务… (Enter 发送，Shift+Enter 换行) | 向要素管理员描述任务… |
| 提问面板底部提示 | Enter 提交 · Escape 跳过 · 文本框内 Ctrl/Cmd+Enter 提交 | 不显示 |
| 确认面板提示 | Enter 同意 · Escape 拒绝 | 不显示 |

触屏文案一律不出现「Enter」「Shift」「Escape」「Ctrl」等按键名。

**1.6 输入区触点**（规则见 4.3）：发送／排队发送、插话、停止在触屏上视觉高度 40px、命中区 44px；两个档位按钮命中区 44px。

### 2. 消息内容

**2.1 Markdown 渲染**（`components/ui/MarkdownRenderer.vue`，共享组件，用户已同意）

- 渲染后给每张表格包一层横向滚动容器：表格保持撑满消息列，列多放不下时按内容撑开，在容器内横向滑动。
- 行内链接与行内代码允许在任意位置断行，长网址不再撑破消息列。
- 窄屏下正文 16px（见 3.2）。
- 桌面不变，滚动条只在内容超宽时出现。

**2.2 用户气泡**（`components/chat/MessageItem.vue`）：段落允许在任意位置断行，长路径、长英文串留在气泡内；气泡最大宽度 80% 不变。

**2.3 本地命令状态行**（`components/chat/MessageItem.vue`）：窄屏下状态文字换行显示，不再单行截断；复制按钮保持可见。

**2.4 向量索引弹窗状态行**（`components/rag/RagIndexModal.vue`）：状态行允许换行——标题、徽标、说明占满一行，「刷新」「构建索引」落到下一行靠右；窄屏内边距由 24px 收到 16px。

**2.5 代码块**（样式在 `components/ui/MarkdownRenderer.vue` 的样式块里，共享组件，用户已同意；做法参照 DeepSeek Harness 的代码块）

- 窄屏下代码自动折行，不用在代码块里横向拖动；桌面保持横向滚动。聊天消息和文件预览的代码块都挂在这份样式下，一处生效。
- 「复制」按钮保持现状，触点不外扩（见 4.3 的豁免）。
- 复制加一条退路：浏览器只在 https（或本机地址）下提供剪贴板接口，手机经 http 地址访问时点「复制」现在没有反应。接口缺失或写入被拒绝时改用旧的复制命令，做法同 DeepSeek Harness；逻辑放进一个小工具函数并补单测，本地命令状态行的复制按钮（2.3）一并改用。这一步要改共享目录里的 `components/ui/CodeBlock.vue`，用户已同意。

**4.3 触点**

两档规则：

| 档位 | 要求 | 适用范围 |
| :-- | :-- | :-- |
| 44 档 | 命中区不小于 44×44 CSS px | 所有独立按钮、图标按钮、列表行、页签、输入框、档位选择器，以及主操作按钮（发送、排队发送、插话、停止、同意执行、拒绝、提交回答、跳过问题） |
| 24 档 | 命中区不小于 24×24，相邻目标间距不小于 8px | 只有两处紧凑带：底部状态栏（28px 高）内的目标、消息流里的过程行（工具调用行、过程折叠组，24px 高） |
| 豁免 | — | 消息正文里的行内文字链接、时间轴与关系图画布内的元素、表格内元素、代码块的复制按钮（纯文字按钮，按 DeepSeek Harness 的做法不外扩） |

做法：

- 视觉尺寸不变的小控件用伪元素外扩命中区，逐元素写工具类（触屏下相对定位加一个铺开四个方向的伪元素），不进全局样式。
- 外扩会压到相邻可点目标时，改为加大控件自身的内边距——行内动作按钮 32px 高、所在行 44px 高。
- 主操作按钮在触屏上视觉高度 40px、命中区 44px。
- 左侧工具栏按钮 40px 高提到 48px（见 4.4）。章节、会话、提示词、技能等列表行在触屏上行高不小于 44px。
- 关闭大纲按钮从 16×16 放大到 28×28（图标不变）。
- 体检脚本：新增 `packages/app/scripts/mobile-ui-audit.js`，一个在页面里执行的浏览器端脚本，不参与构建、不被应用引用。它枚举可见的可点元素，按「元素矩形加伪元素外扩矩形」算命中区，输出不达标清单和命中区相互重叠的相邻目标。用法写在脚本头部。

**手机真机（阶段 5，最终确认）**

1. 对话页：输入卡片完整在屏内，工具行不溢出，两个档位菜单完整可见、可滚动。
2. 提问接管、重命名／删除确认出现时：面板完整，文字横排，能滚到底，按钮点得到。
3. 软键盘弹出：输入卡片贴在键盘上方不被遮挡；回车换行；发送、排队、插话用按钮。
4. 含表格、长链接、长路径、代码块的消息：不出屏幕，表格可横向滑动，代码自动折行，点「复制」后出现「已复制」。
5. 字号：消息、正文、输入框 16px，看不到 12px 以下的文字。
6. 左侧工具栏有文字标签；分类抽屉延伸到右缘；关闭按钮好点。
7. 首页：移除按钮常显，副标题单行。
8. 长按图标按钮出提示。
9. 设置、时间线、关系图谱、向量索引弹窗：不超出屏幕，内容能滚到底，滚到头不触发下拉刷新、背景不滚。
10. 设置页签：切到靠后的页签时自动滚到可见。

软键盘、安全区、下拉刷新三项只能在真机上确认。

**降级方案**：真机不可用时（手边没有手机、调试连接不上），真机项整体转入未验证清单并在施工日志注明，不视为通过。

## 本项目规范核对

- **架构边界**：全部改动在 `packages/app` 的界面层，不碰 `@novai/core`；不读写项目文件，不引入 Node 文件接口。
- **共享文件**：用户已同意的四个——页面入口 `packages/app/index.html`、`components/ui/MarkdownRenderer.vue`、`packages/app/src/style.css`（只动输入框字号那一条及其窄屏媒体查询）、`components/ui/BaseModal.vue`；另加 `components/ui/Tooltip.vue`（见 4.2 的说明）和 `components/ui/CodeBlock.vue`（见 2.5 的复制退路），用户已同意。除此之外不动 `tsconfig.json`、`vitest.config.ts`、根目录 `package.json` 的脚本、路由、`stores/index.ts`、`App.vue`、`main.ts`、全局样式的其它规则、`AGENTS.md`、`CLAUDE.md`。Tailwind 不加主题覆盖、不加自定义工具类——触点外扩用逐元素的工具类。
- **既有术语**：「插话」「排队发送」「完全访问」「去审阅」等现有文案不变。
- **测试**：布局类改动在 happy-dom 里量不到，靠应用内浏览器实测加类名断言；逻辑类改动（按键解析、文案切换、提示计时）用单测覆盖。
- **提交**：按阶段门禁提交，每个逻辑单元一个提交。`docs` 是子模块，先提交子模块再推进父仓库指针；提交说明的范围用 `view`（输入区与消息）、`ui`（通用组件）、`layout`（工具栏、状态栏、抽屉）、`style`（全局样式的输入框字号）、`app`（页面入口声明）、`docs`。
- **测试项目红线**：真机与仿真验收用的 `~/note/test-novel`，其密钥只在运行时读取，绝不写进本仓库任何文件；OPFS 副本只存在于浏览器存储与 `/tmp`。

## 已拍死的取舍

1. **左侧工具栏**：保留竖条，补文字标签。不做底部标签栏，不做抽屉式导航。
2. **看板卡片移动**：不改。卡片详情里已经能设置状态与所属列，拖动保持现状。
3. **图标说明**：重要的写出来，其余长按查看。不做「点按即显示」，不做全部改成常显文字。
4. **共享文件**：用户点名的四个文件纳入本计划；通用提示组件因长按查看一并纳入。
5. **手机键盘回车**：换行。发送、排队、插话走按钮；`Ctrl/Cmd+Enter` 插话保留；命令菜单打开时回车同样换行。
6. **字号**：只做三处——12px 下限、窄屏正文 16px、窄屏输入框 16px。不整体放大 12px 基准，不动根字号，桌面 14px 正文不变。
7. **触点两档**：44 档为主；24 档只给底部状态栏和消息流过程行。
8. **触屏判定**：用媒体特性，不加「手机模式」开关，不记忆用户选择。
9. **弹窗**：不做过渡动画、不监听 Esc、不做焦点陷阱，沿用外壳现状。
10. **悬停才显示的按钮**：触屏上常显，不做首次进入时的引导提示。
11. **接管面板限高**：视口的 60%，面板内滚动；不做全屏接管。
12. **输入区高度上限**：保持固定值 200px，不按视口高度算。DeepSeek Harness 也是固定上限、不随视口伸缩，只是它的值更大（14 行）；调大上限会改变桌面输入区的外观，不在本计划范围内。输入区的高度与滚动位置由 `components/chat/composer-height.ts` 负责。

## 迁移条款

- 纯界面行为变化，无数据迁移：不涉及项目文件格式、本地存储结构、配置项。
- 回车换行只改变按键行为，已有草稿不受影响。
- 原生悬停提示迁到通用提示组件不产生数据。

## 明确不做清单

- 看板卡片的拖动与移动（取舍 2）。
- 左侧工具栏改底部标签栏或抽屉式导航。
- 整体放大字号（根字号、12px 基准、桌面 14px 正文）。
- iOS Safari 的专项适配与验收——用户设备为安卓；顺带收益（16px 输入框避免聚焦放大）不单独验证。
- 弹窗的过渡动画、Esc 关闭、焦点陷阱。
- 双击交互的替换与触屏提示——另有可见入口，交互发现性是另一个主题。
- 全局禁用下拉刷新——需要改全局样式里根元素的规则，未获授权；本计划用滚动约束覆盖主要滚动路径。
- 去除触摸高亮色——去掉而没有替代的按压态会降低反馈。
- 横屏专项布局——只保证输入区与接管面板在 800×360 下可用。
- 输入区高度上限按视口高度调整（取舍 12）。
- 时间轴与关系图画布内部的触点——画布交互另有安排。
- 首页与设置页以外的重排。
