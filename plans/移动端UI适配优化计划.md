## 背景与问题

用户用安卓手机访问正式站时，对话输入区有两处破损：智能体运行中，「完全访问」被挤成一字一行，「插话」「低」「排队发送」伸出输入卡片；空闲时思考强度菜单左缘落到屏幕外、标签折行。根因是输入区工具行不换行、档位按钮允许被压缩、菜单在窄屏按固定宽度定位。这一批已修复，`pnpm typecheck` 与 `pnpm test`（161 个文件 2002 例）全绿。

修复后按手机视口（360×800）做了第二轮走查，量到的问题按严重程度排列：

| 程度 | 现象 | 量到的数值 |
| :-- | :-- | :-- |
| 破损 | 智能体提问接管面板：底部提示被右侧按钮组挤成竖条，面板底边贴到视口外 | 提示宽 14px、竖排 15 行；软键盘弹出后的高度（360×500）下面板 475px |
| 破损 | 重命名／删除确认面板：说明文字列只剩一条，面板高过屏幕 | 文字列宽 10px；面板高 970–1043px，视口只有 800px |
| 溢出 | 消息里的表格没有滚动外壳，裸链接一行伸出屏幕右缘 | 357px 的表塞进 272px 的列；链接宽 609px |
| 溢出 | 用户气泡里的长路径不换行；向量索引弹窗的状态说明被右侧按钮挤到截断 | 文字宽 224px，气泡只有 186px |
| 看不清 | 排队栏只露出消息开头，行内按钮又小又矮 | 消息露出 146px（共 406px）；按钮 24×16、48×16 |
| 够不着 | 首页「移除最近项目」、提示词列表的大纲标记只在悬停时出现，触屏上永远不显示 | 按钮 28×28 |
| 够不着 | 左侧工具栏全是纯图标，说明只在悬停提示里；而手机上它是分类抽屉的唯一入口 | 竖条 56px 宽，按钮 40×40 |
| 看不到 | 说明只写在浏览器原生悬停提示里，触屏上无从查看 | 68 处，分布在 36 个文件 |
| 字太小 | 带字号的标签、徽标、时间戳大量落在 10–11px；消息正文与小说正文 14px；输入框 15px | 10px 约 1.6mm，11px 约 1.7mm（安卓 1 CSS px = 1/160 英寸） |
| 键盘导向 | 占位符与提示教用户「回车发送、Shift+回车换行」，手机软键盘的回车键因此变成发送 | 输入区共 5 处按键说明文案 |
| 弹窗 | 通用弹窗外壳不限内容高度、左右才有内边距，关闭按钮 28×28；多个弹窗按静态视口高度定高 | 弹窗高 88vh、90vh |
| 页面 | 页面入口只声明了宽度与缩放，没有安全区与软键盘行为的声明 | — |

两块接管面板与当初的输入区缺陷是同一个根因：一行里塞了文字和按钮组，文字列允许被压到零宽。它们比输入区更严重，因为面板在手机上会整块超出屏幕。

字号方面，全站以 12px 为最小档（通用小号样式 441 处，分布在 74 个文件），但另有 122 处写了 10px 或 11px 的固定字号，低于 iOS 与安卓原生设计规范里最小的 11pt／11sp。

左侧工具栏的手机形态在《UI 重构计划》里被推到「移动端专项」，本计划承接。

## 目标形态（用户已拍板）

1. 手机上（含软键盘弹出后）所有面板都在屏幕内完整可读、可滚动，不再出现文字被挤成竖条的面板。
2. 消息、表格、链接、路径都在屏幕宽度内可读，超出部分在自己内部滚动。
3. 最小字号 12px；手机上消息正文与小说正文 16px；输入框 16px。不整体放大 12px 基准。
4. 触屏上每个操作都够得着、看得懂：悬停才出现的按钮直接显示；图标说明「重要的写出来，其余长按查看」；触点达标。
5. 左侧工具栏保留竖条，图标下补文字标签。
6. 手机键盘回车是换行；发送、排队、插话用按钮。
7. 弹窗不出屏幕、背景不串滚；高度按动态视口算；页面按安全区与软键盘正确布局。

## 适用范围与约定

- **窄屏**：视口宽小于 640px，对应样式前缀 `max-sm:`。只在窄屏生效，桌面不变。
- **触屏**：主输入设备是触摸，对应样式前缀 `pointer-coarse:`（项目所用 Tailwind 4.3.0 自带，此前未用过）。悬停相关的兜底沿用各模块已有断点：分类列表用 `max-lg:`，首页用 `pointer-coarse:`。
- 回车换行需要脚本判断，用媒体查询 `(pointer: coarse)`，与上面的样式前缀同源，见 1.1。
- 桌面（鼠标、宽度不小于 640px）的外观与交互不变。唯二例外是静态视口高度改动态视口高度、弹窗外壳的限高与内边距——桌面同样受益，且没有可见差异。
- 本文路径均相对 `packages/app/src/`，另有说明的除外。

## 方案

### 1. 聊天输入区

**1.1 手机键盘回车换行**（`components/layout/ChatPanel.vue`、`composables/keyboard.ts`、`constants/agent-roles.ts`）

- 主输入设备为触摸时，对话输入框里的回车一律交给编辑器换行，不再触发发送或排队。
- 斜杠命令菜单、`@` 大纲弹层、`#` 技能弹层打开时同样换行：触屏上这些菜单用点按选择，方向键加回车是键盘操作，软键盘弹出时回车仍是用户的换行键。
- `Ctrl/Cmd+Enter` 保持插话不变，外接键盘照常可用。输入法组合中的回车维持现状：只拦掉默认行为，不换行。
- 发送、排队发送、插话、停止仍由工具行按钮触发。
- 编辑器宿主加 `enterkeyhint="enter"`，让软键盘的回车键显示成换行样式。
- 判定集中在一处：`composables/keyboard.ts` 新增一个只读判定函数，内部读 `(pointer: coarse)` 媒体查询；按键解析函数增加触屏参数。测试通过参数注入，不依赖运行环境。
- 单行输入框（搜索、设置表单、排队栏的行内编辑）不在此列，回车提交是它们的常规行为。

**1.2 智能体提问接管面板**（`components/chat/QuestionTakeover.vue`）

- 面板限高为视口的 60%（动态视口高度），内部纵向排列：标题与底部按钮固定，中间的问题说明、选项、补充文本框在面板内滚动。面板取代输入卡片出现，限高后至少给消息区留下三分之一屏幕。
- 底部提示只在「非窄屏且非触屏」显示（内容是键盘操作说明，见 1.5）；右侧按钮组独占一行，按钮文字不折行。
- 实现只用样式，不走脚本量高。

**1.3 重命名／删除确认面板**（`components/chat/WriteActionTakeover.vue`）

- 窄屏上下堆叠：说明文字占满整行，按钮组落到下方靠右。宽屏保持现在的左右排列，但文字列设最小宽度，不再被压成竖条。
- 面板同样限高为视口的 60%，内容内滚（重命名会列出长路径）。
- 键盘提示按 1.5 的规则隐藏；回车同意、Escape 拒绝的键盘行为保留——它只在外接键盘、焦点不在按钮上时触发。

**1.4 排队栏**（`components/chat/QueueDock.vue`）

- 窄屏下消息文字直接换行显示，最多 3 行，超出省略，不再单行截断。
- 行内「编辑／删除／立即插话」在触屏上视觉高度 32px、所在行高 44px；按钮文字不折行。
- 标签字号按第 3 节提到 12px。

**1.5 文案按输入方式切换**

输入区文案集中到一个小模块（新增 `constants/composer-copy.ts`），按「空闲／运行中」与「鼠标键盘／触屏」四种组合给出，组件不再散写。

| 位置 | 鼠标键盘（现状，不变） | 触屏 |
| :-- | :-- | :-- |
| 输入占位（空闲） | 输入创作指令... (Enter 发送，Shift+Enter 换行；输入 @ 切换大纲) | 输入创作指令...（输入 @ 切换大纲） |
| 输入占位（运行中） | Agent 运行中：Enter 排队发送，Ctrl/Cmd+Enter 插话，Shift+Enter 换行 | Agent 运行中：发送的消息会排队，点「插话」可在下一步前插入 |
| 要素管理员占位（`constants/agent-roles.ts`） | 向要素管理员描述任务… (Enter 发送，Shift+Enter 换行) | 向要素管理员描述任务… |
| 提问面板底部提示 | Enter 提交 · Escape 跳过 · 文本框内 Ctrl/Cmd+Enter 提交 | 不显示 |
| 确认面板提示 | Enter 同意 · Escape 拒绝 | 不显示 |

触屏文案一律不出现「Enter」「Shift」「Escape」「Ctrl」等按键名。

**1.6 输入区触点**（规则见 4.3）：发送／排队发送、插话、停止在触屏上视觉高度 40px、命中区 44px；两个档位按钮命中区 44px。

### 2. 消息内容

**2.1 Markdown 渲染**（`components/ui/MarkdownRenderer.vue`，共享组件，用户已同意）

- 渲染后给每张表格包一层横向滚动容器：表格保持撑满消息列，列多放不下时按内容撑开，在容器内横向滑动。
- 行内链接与行内代码允许在任意位置断行，长网址不再撑破消息列。
- 窄屏下正文 16px（见 3.2）。
- 桌面不变，滚动条只在内容超宽时出现。

**2.2 用户气泡**（`components/chat/MessageItem.vue`）：段落允许在任意位置断行，长路径、长英文串留在气泡内；气泡最大宽度 80% 不变。

**2.3 本地命令状态行**（`components/chat/MessageItem.vue`）：窄屏下状态文字换行显示，不再单行截断；复制按钮保持可见。

**2.4 向量索引弹窗状态行**（`components/rag/RagIndexModal.vue`）：状态行允许换行——标题、徽标、说明占满一行，「刷新」「构建索引」落到下一行靠右；窄屏内边距由 24px 收到 16px。

**2.5 代码块**（样式在 `components/ui/MarkdownRenderer.vue` 的样式块里，共享组件，用户已同意；做法参照 DeepSeek Harness 的代码块）

- 窄屏下代码自动折行，不用在代码块里横向拖动；桌面保持横向滚动。聊天消息和文件预览的代码块都挂在这份样式下，一处生效。
- 「复制」按钮保持现状，触点不外扩（见 4.3 的豁免）。
- 复制加一条退路：浏览器只在 https（或本机地址）下提供剪贴板接口，手机经 http 地址访问时点「复制」现在没有反应。接口缺失或写入被拒绝时改用旧的复制命令，做法同 DeepSeek Harness；逻辑放进一个小工具函数并补单测，本地命令状态行的复制按钮（2.3）一并改用。这一步要改共享目录里的 `components/ui/CodeBlock.vue`，用户已同意。

### 3. 字号

**3.1 10px／11px 提到 12px**（全站 122 处）

- 写死的 10px、11px 字号一律改用通用小号样式（12px）；`components/card-board/ChapterPicker.vue` 样式块里的三处 11px 同步改 12px；唯一一处 13px（`components/ui/FrontmatterCard.vue` 的卡片标题）并入 14px。
- 不动通用小号样式本身。
- 集中在十个文件：`components/rhythm/RhythmDetailPanel.vue`（34 处）、`components/foreshadowing/ForeshadowingDetailPanel.vue`（15）、`components/card-board/PlannedPositionPicker.vue`（8）、`components/card-board/RhythmBoardPanel.vue`（6）、`components/chat/WriteConfirmPanel.vue`（6）、`components/layout/FilePanelBody.vue`（4）、`components/chat/TurnChangesPanel.vue`（4）、`components/chat/AskUserQuestionCard.vue`（4）、`components/card-board/CardConflictCompare.vue`（4）、`components/timeline/TimelineDetail.vue`（3），其余二十余个文件各 1–3 处。
- 风险是个别紧凑行变高。门禁里在 360 宽下检查这些组件没有新增溢出。

**3.2 消息正文与小说正文 16px（窄屏）**

- 对话消息：助手消息的 Markdown 正文、用户气泡文字在窄屏下 16px，行高不小于 1.6。时间戳、工具调用行、徽标等辅助信息保持 12px。
- 小说正文（`components/layout/FilePanelBody.vue` 的正文预览）：窄屏下 16px、行高 28px。
- Markdown 正文由渲染组件自己定字号，所以在该组件的样式里加窄屏媒体查询；其它使用该组件的地方（卡片详情预览等）在窄屏下一并变成 16px，属于预期。
- 桌面保持 14px。

**3.3 输入框 16px（窄屏）**（`packages/app/src/style.css` 的输入框基础类，用户已同意）

- 在现有 15px 规则之后追加一条窄屏媒体查询，把输入框基础类的字号设为 16px。编辑器宿主、补全镜像层、占位层共用这个类，三者同步、不会错位。
- 顺带收益：iOS Safari 聚焦小于 16px 的输入框会自动放大页面，16px 可以避免。
- 桌面保持 15px。

### 4. 触屏可达性

**4.1 悬停才出现的按钮**

| 位置 | 现状 | 改法 |
| :-- | :-- | :-- |
| 首页最近项目的「移除」（`views/HomeView.vue`） | 悬停才显示 | 加 `pointer-coarse:opacity-100`，触屏常显 |
| 提示词列表的大纲标记（`components/category/PromptList.vue`） | 悬停才显示 | 加 `max-lg:opacity-100`，与同族技能列表的现有做法一致 |

其余悬停显隐已带断点兜底（技能列表、会话列表），不动。

**4.2 图标说明：重要的写出来，其余长按查看**

写出来的四处：

1. 插话与排队的区别——运行中的输入占位符直接说明（1.5）。
2. 排队消息全文——排队行换行显示（1.4）。
3. 本地命令结果——状态行换行显示（2.3）。
4. 状态栏的运行状态与大纲名——点按弹出完整文字，改用通用提示组件替换原生悬停提示。

长按查看：

- 通用提示组件（`components/ui/Tooltip.vue`，共享组件）增加触屏支持：触摸按住满 400ms 显示提示，松手后保留 1 秒再消失。鼠标悬停与键盘聚焦的行为不变。提示层已经传送到页面根节点下，不会被抽屉和弹窗裁切。
- 迁移范围：手机上可见、且没有可见文字标签的图标按钮，从原生悬停提示改挂通用提示组件。首批清单：对话头部的「打开内容面板」与「项目主页」、内容面板关闭按钮（`components/layout/PanelHeader.vue`）、分类面板关闭按钮（`components/layout/MobilePanelClose.vue`）、弹窗关闭按钮（`components/layout/WorkspaceModal.vue`）、预览／编辑切换（`components/layout/ViewModeToggle.vue`）、关闭大纲（`components/layout/IndexStatusBar.vue`）、首页「移除最近项目」。
- 有可见文字标签的按钮，其补充说明保持原生悬停提示——手机上不展示，但不影响操作。
- **说明**：通用提示组件不在用户点名的四个共享文件里，它是「长按查看」这一决定必然要改的文件，在此单列。

**4.3 触点**

两档规则：

| 档位 | 要求 | 适用范围 |
| :-- | :-- | :-- |
| 44 档 | 命中区不小于 44×44 CSS px | 所有独立按钮、图标按钮、列表行、页签、输入框、档位选择器，以及主操作按钮（发送、排队发送、插话、停止、同意执行、拒绝、提交回答、跳过问题） |
| 24 档 | 命中区不小于 24×24，相邻目标间距不小于 8px | 只有两处紧凑带：底部状态栏（28px 高）内的目标、消息流里的过程行（工具调用行、过程折叠组，24px 高） |
| 豁免 | — | 消息正文里的行内文字链接、时间轴与关系图画布内的元素、表格内元素、代码块的复制按钮（纯文字按钮，按 DeepSeek Harness 的做法不外扩） |

做法：

- 视觉尺寸不变的小控件用伪元素外扩命中区，逐元素写工具类（触屏下相对定位加一个铺开四个方向的伪元素），不进全局样式。
- 外扩会压到相邻可点目标时，改为加大控件自身的内边距——行内动作按钮 32px 高、所在行 44px 高。
- 主操作按钮在触屏上视觉高度 40px、命中区 44px。
- 左侧工具栏按钮 40px 高提到 48px（见 4.4）。章节、会话、提示词、技能等列表行在触屏上行高不小于 44px。
- 关闭大纲按钮从 16×16 放大到 28×28（图标不变）。

## 明确不做清单

- 看板卡片的拖动与移动（取舍 2）。
- 左侧工具栏改底部标签栏或抽屉式导航。
- 整体放大字号（根字号、12px 基准、桌面 14px 正文）。
- iOS Safari 的专项适配与验收——用户设备为安卓；顺带收益（16px 输入框避免聚焦放大）不单独验证。
- 弹窗的过渡动画、Esc 关闭、焦点陷阱。
- 双击交互的替换与触屏提示——另有可见入口，交互发现性是另一个主题。
- 全局禁用下拉刷新——需要改全局样式里根元素的规则，未获授权；本计划用滚动约束覆盖主要滚动路径。
- 去除触摸高亮色——去掉而没有替代的按压态会降低反馈。
- 横屏专项布局——只保证输入区与接管面板在 800×360 下可用。
- 输入区高度上限按视口高度调整（取舍 12）。
- 时间轴与关系图画布内部的触点——画布交互另有安排。
- 首页与设置页以外的重排。
