## 维护规则

1. 新的大功能、重构或跨模块调整，先编写具体计划，再补充本索引入口。
2. 设计、待办、执行状态、偏差和验收写入对应计划，不在索引中另建进度副本。
3. 计划完成后保留正文和施工日志，不因状态变化反复改写索引摘要。
4. 已失去执行价值但仍有回溯意义的材料移动到 `../archive/`，并更新原位置的链接。
