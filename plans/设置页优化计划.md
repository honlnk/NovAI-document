# 设置页优化计划

## 记录时间

2026-08-18

## 文档目的

重启项目后的第一批前置优化：重构设置页的布局与模型配置交互，统一自动保存体验，补齐模型列表获取与测试连接能力。属于基础设施优化，不新增创作功能。

## 需求清单（来自用户）

1. 设置页布局照抄同级参考项目 `gpt-image-studio`（ActivityBar 入口不变，模态框内部布局一致）。
2. 模型配置交互借鉴同级参考项目 `duet`：不做 multi-provider，单一配置；支持协议选择与获取模型列表；不做价格计算。
3. 去掉保存按钮，改为自动保存；右下角放关闭按钮；测试按钮放到更合适的位置。
4. 调研 embedding / rerank 的协议通用性，决定是否需要协议选择；模型列表尽量只拉本配置需要的模型。
5. 补齐 Rerank 与输入补全的测试连接按钮。

## 调研结论

### 参考项目

- **gpt-image-studio**：Vue3 + Tailwind v4（CSS-first，无主题 token）。设置模态框为三段式骨架——header（标题 + X）/ body（左侧 `md:w-44` 竖排 tab 导航 + 右侧 `p-5 overflow-y-auto` 内容）/ footer（右对齐黑色「关闭」按钮）；尺寸 `h-[min(88vh,44rem)] max-w-4xl rounded-lg shadow-xl`；无动画、无 Esc 监听；tab 记忆 localStorage；字段样式词汇统一（label 上方、`rounded-lg border-gray-300 focus:border-gray-500` 输入框、iOS 风格开关行）。
- **duet**：后端代理多协议适配（`ProviderAdapter` 工厂 + openai / openai-responses / anthropic / gemini 四适配器）。值得借鉴的单配置部分：协议 select 三合一（value / label / 各协议默认 baseUrl 联动）、「获取列表」拉取模型（手输永远允许 + 浮层下拉过滤）、协议决定 listModels 端点与鉴权（anthropic 用 `x-api-key` + `anthropic-version`，gemini 用 key）。

### 协议调研（第 4 条的答案）

- **Embedding 无需协议选择**：业界已通用 OpenAI 兼容 `/embeddings` 协议，阿里百炼的 `compatible-mode/v1` 完全兼容（官方文档确认）。
- **Rerank 无需新增协议字段**：无统一标准，但现有 `rerank-client.ts` 已按 baseUrl 嗅探（`isDashScopeBaseUrl`）自动切换百炼原生协议与 Jina/Cohere 风格，且响应解析兼容 `results` 与 `output.results` 两种格式。
- **附注**：gte-rerank 已于 2026-05-30 下线，官方推荐 qwen3-rerank；过滤规则覆盖两者。
- **LLM 多协议**（用户确认）：本期仅配置层支持 openai / openai-responses / anthropic / gemini 四种（协议选择、拉列表、测试连接；OpenAI 有 Chat Completions 与 Responses 两套协议，Responses 的模型列表端点同为 `GET /models`），对话生成链路仍走 OpenAI 兼容；其余协议的生成适配（流式 + tool_calls 解析）另立后续计划。
- **模型列表过滤**：各家 `/models` 均无类型过滤参数，采用「全量拉取 + 客户端按用途过滤 + 可切换显示全部」策略。

## 实施内容

### core 层

- 新增 `core/ai/models-client.ts`：
  - `listAvailableModels`：多协议拉取（openai `GET /models`、anthropic `GET /v1/models` 带 `x-api-key` + `anthropic-version` + `anthropic-dangerous-direct-browser-access`（浏览器直连 CORS）、gemini `GET /v1beta/models` 带 `x-goog-api-key`）；15s 超时；DashScope 原生地址自动改写为 `compatible-mode/v1`（修复百炼 rerank 场景 `GET /models` 404 的问题）。
  - `filterModelsByPurpose`：embedding / rerank / llm 三类启发式过滤（宽松规则，llm 排除明显非对话模型）。
  - `testConnectionViaModelList`：共享的测试连接实现——拉到列表即成功；model 已填时检查包含性并提示（不判失败）。
- 4 个 `testConnection`（llm / embedding / rerank / completion）改为上述薄壳，删除各自重复的 `GET /models` 样板。
- `llm.protocol` 配置字段（`'openai' | 'anthropic' | 'gemini'`，默认 `'openai'`）：`types/ai.ts` 加 `ModelProtocol`，`types/project.ts` / `services/types.ts` / `defaults.ts` 同步；normalize 浅合并自动兜底。
- `settings-service`：新增 `testCompletion`（原 core 已实现但 service→UI 断链）与 `listModels`（带 purpose 过滤双列表）。
- `ai/shared.ts`：导出 `appendProxyHeader`（非 Bearer 协议头的 DEV 代理补充）。

### app 层

- 新增 `ui/BaseModal.vue`（照抄 gpt-image-studio：Teleport + 遮罩 + mousedown.self 关闭，无动画无 Esc）与 `ui/ToggleSwitch.vue`（iOS 风格开关）。
- 重写 `SettingsModal.vue` 为三段式骨架 + 左侧竖排 tab（tab 记忆 `novai:settings-tab`），624 行单文件拆为 5 个面板组件：
  - `LlmSettingsPanel` / `EmbeddingSettingsPanel` / `RerankSettingsPanel` / `CompletionSettingsPanel` / `ProjectSettingsPanel`。
- 新增 `settings/ModelEndpointFields.vue` 共享字段组（四个模型面板复用）：
  - 协议 select（仅 LLM）+ 切换联动默认地址（不覆盖自定义地址）+ 非 openai 协议的「生成链路适配中」信息条；
  - 模型名输入组：「获取列表」按钮（前置校验 baseUrl/apiKey）+ 浮层下拉（输入过滤、用途过滤 + 显示全部切换）+ 手输永远允许；
  - 统一「测试连接」按钮 + 内联结果提示条（四个面板全具备，补齐 rerank / completion 的缺口）。
- **自动保存**（去掉全部保存按钮）：
  - 面板 reactive form 直接修改 → SettingsModal 统一 watch → 防抖 600ms 合并 patch → `saveConfig` → `updateCurrentProjectConfig`（沿用双 store 同步链路）；
  - enabled 开关变化经 `save-immediately` 事件立即 flush（下个宏任务，等 watch 先并入队列）；
  - 关闭前 `await flushSave()`；footer 左侧状态小字（更改会自动保存 / 保存中… / 已自动保存 / 失败点击重试），失败另发 toast；
  - 回填期间 `isInitializing` 挂起，避免磁盘数据回写触发无意义保存。

### 百炼模型列表的内置清单与文档页（追加，2026-08-18）

真实使用发现：百炼 `compatible-mode/v1/models` **不返回 embedding / rerank 模型**（列表主要是 qwen 系对话模型），「获取列表」拿不到 `text-embedding-v4` / `qwen3-rerank` 等可选项。经用户确认的修复方向：**不再依赖百炼接口拉取这两类模型，改为 NovAI 内置清单维护**。

- 新增 `core/ai/dashscope-models.ts`：内置清单（含模型 ID、一句话定位、通俗介绍、关键规格、推荐/下线标记）+ `resolveDashScopeBuiltinModels`（百炼地址 + embedding/rerank 用途时返回清单 ID，其余返回 null 走 API）。`isDashScopeBaseUrl` 收敛到该文件单一实现。
  - embedding：`qwen3.7-text-embedding`（最新，指令遵循比 v4 +16.4%）、`text-embedding-v4`（100+ 语种、64~2048 维、8192 token）、`text-embedding-v3`（上一代）。
  - rerank：`qwen3-rerank`（推荐，gte-rerank 官方替代，单次 12 万 token）、`gte-rerank-v2`（上一代，单次 3 万）、`gte-rerank`（已下线，仅文档说明，不进下拉）。
- `settings-service.listModels`：命中内置清单时直接返回（`source: 'builtin'`），不发请求；LLM 等其余场景照旧走 API。
- `testConnectionViaModelList` 增加可选 `purpose`：百炼 embedding/rerank 场景的模型名包含性校验并入内置清单，避免「连接成功但列表中未见该模型」的误导提示。
- 新增文档页 `/model-docs`（`ModelDocsView.vue`，新标签页打开）：用通俗语言解释 Embedding/Rerank 在 NovAI 里的作用（找得全不全 / 排得准不准）、每个模型的介绍与规格、多模态向量模型为何不列、gte-rerank 下线提醒；数据直接读内置清单，列表与文档自动同步。模型输入框 label 行新增「模型说明」入口（仅 embedding / rerank 面板显示），模型 ID 支持点击复制。
- 补 `dashscope-models.test.ts` 8 例（清单解析、下线模型排除、数据完整性、测试连接的 purpose 校验）。

## 验收标准

- 设置页布局与 gpt-image-studio 一致：左侧竖排导航、三段式骨架、右下角黑色关闭按钮。
- 修改任意字段停顿后自动保存，footer 状态正确流转；关闭时未落盘修改不丢失。
- 四个模型面板均可「获取列表」与「测试连接」；列表按用途过滤且可切全量。
- LLM 面板可切换协议，切换时默认地址联动；非 openai 协议显示生成链路提示。
- 百炼 rerank 场景：填 dashscope 原生地址可正常拉列表与测试（compatible-mode 自动改写）。
- 全量 typecheck / vitest / build 通过。
