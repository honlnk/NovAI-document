# NovAI 当前进度

本页用于快速了解项目目前具备的主要能力和所处阶段。具体施工状态、待办和验收结果见[计划索引](../plans/README.md)。

## 当前阶段

项目已越过基础闭环验证，形成由对话驱动、通过工具和本地文件创作小说的智能体工作台。

当前重点是持续验证真实长篇创作中的质量：要素是否维护得准确，剧情检索是否有效，长会话压缩后是否仍能保持连贯，以及多角色协作是否符合用户意图。

## 项目与创作工作台

- 在浏览器中创建、打开、修复和恢复本地小说项目，查看最近项目与内容统计。
- 以项目文件保存章节、要素、提示词、大纲和配置，支持预览、编辑和外部编辑器协作。
- 对话是 Agent 控制面，正文和设定不依赖聊天记录保存。
- 内容面板与文件树会响应 Agent 写入；删除文件先进入项目回收站。
- 支持写入确认、差异预览、运行停止、排队和插话，以及按会话查看文件变更。
- 主智能体可在任务中途主动提问：结构化问题以独立卡片呈现（单选、多选、自由文本可并存），等待期间普通输入即作答，答案回灌后原任务继续；停止与刷新不遗留不可操作的等待。

## Agent 与上下文

- Agent Loop 参考 DeepSeek Harness，区分模型消息与聊天展示。
- 支持上下文压缩、分页读取、超长工具结果溢出保存与取回。
- 项目记忆和写作大纲按需进入模型视图，不自动注入近期章节。
- 章节、提示词和具体文件通过导航与读取工具按需获取。
- 写权限覆盖审阅、章节、素材、章节与素材、完全访问五档，内部目录另有硬保护。
- 主动提问工具仅主智能体拥有（要素管理员直聊与委派不装配）；提问是只读交互，不进确认链与变更账本。

## 要素与多角色

- 主智能体负责创作、文件操作、外部资料查询和任务委派。
- 要素管理员维护人物、地点、实体、情节、时间线和世界观，支持直聊与独立委派会话。
- 委派会话保留完整工具过程、独立确认和变更记录，主会话接收结果汇报。
- 稳定要素先通过目录披露，再按名称批量加载完整内容。
- 情节和时间线通过语义检索召回，必要时可重排；章节不进入要素向量索引。
- 索引状态在工作区可见，用户可触发全量或指定来源的重建。

## 模型与外部资料

- 对话模型支持 OpenAI Chat Completions、OpenAI Responses、Anthropic 和 Gemini 协议。
- 流式正文、思考过程和工具调用统一进入 Agent 事件链。
- Embedding、Rerank 和输入补全独立配置。
- 支持联网搜索、网页阅读和知识平台条目查询，外部资料与本地文件写入分离。

## 主要界面能力

- 主工作区包含分类导航、对话面板和可编辑内容面板。
- 聊天展示流式回复、工具轨迹、写入确认和按文件聚合的差异。
- 输入框基于 Lexical，支持大纲引用、斜杠命令和可选的行内补全。
- 设置覆盖模型、检索、联网、权限、要素管理员和项目参数。
- 浏览器能力不满足要求时，首页直接显示环境阻塞原因。

## 需要持续观察

- 真实长篇项目中，要素摘要与整理质量能否支撑稳定、低成本的召回。
- 语义检索的触发时机、候选质量与重排效果。
- 上下文压缩后的剧情连贯性，以及长任务的停止、恢复和队列体验。
- 要素目录随项目规模增长后的上下文成本。
- 不同模型供应商和代理网关的协议兼容性。

上述观察不等同于已经排期的施工待办。确定要实施的改动应先形成具体计划。

## 已形成计划、尚未开工

截至 2026-11-03，[Agent 主动提问工具计划](../plans/Agent主动提问工具计划.md) 已形成独立设计，尚未开工。该工具供主智能体在任务执行中提出单选、多选或自由文本问题，获得回答后继续原任务；普通聊天提问和文件写入确认保持原有职责。

多步任务工具（todo_write）仍在设计讨论阶段，尚无独立计划，不属于当前施工范围。
