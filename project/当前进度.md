## Agent 与上下文

- Agent Loop 参考 DeepSeek Harness，区分模型消息与聊天展示。
- 支持上下文压缩（达到阈值自动触发，也可用 /压缩上下文 斜杠命令随时手动触发）、分页读取、超长工具结果溢出保存与取回。
- 项目记忆和写作大纲按需进入模型视图，不自动注入近期章节。
- 章节、提示词、计划卡片和具体文件通过导航与读取工具按需获取；计划目录不进入语义索引。
- 文件查找按修改时间降序，超限结果跨顶层目录采样展示、完整列表存入溢出文件可取回；内容搜索默认字面匹配、带行号与上下文（正则可选、超限同样落溢出文件），查「人名/词语出现在哪些章节」用内容搜索，语义联想才走 RagSearch；内容搜索仅主智能体装配。
- EditFile 支持空文件以空旧文本直接填充；同一轮次连续编辑免重复读取，外部改动仍按修改时间与大小校验拦截（内容哈希兜底）。
- 主智能体可查询、读取、新建、修改和删除计划卡片，正文更新须先读后写防覆盖；要素管理员不持有计划工具。
- 写权限覆盖审阅、章节、素材、章节与素材、完全访问五档，内部目录另有硬保护。
- 内部文件（novel.config.json、.novel/、.novai/）对模型整体不可见：不出现在目录列表、文件查找与内容搜索中，读写指向时统一报教学式说明并引导改用上下文已有信息或直接询问用户；唯一例外是 .novel/spill/ 溢出取回通道（可读、可显式搜索，仍禁写）。
- 主动提问工具仅主智能体拥有（要素管理员直聊与委派不装配）；提问是只读交互，不进确认链与变更账本。

## 要素与多角色

- 主智能体负责创作、文件操作、外部资料查询和任务委派。
- 要素管理员维护人物、地点、实体、情节和世界观（时间线不再是要素，见下方「时间线事件账本」），支持直聊与独立委派会话。
- 委派会话保留完整工具过程、独立确认和变更记录，主会话接收结果汇报。
- 稳定要素先通过目录披露，再按名称批量加载完整内容。
- 情节通过语义检索召回，必要时可重排；章节不进入要素向量索引；时间线不做语义索引，由时间线工具确定性查询（见下方「时间线事件账本」）。
- 索引状态在工作区可见，用户可触发全量或指定来源的重建。

## 时间线事件账本

- 时间线于 2026-11-22 由多篇 Markdown 要素改造为项目级事件账本 `elements/timeline.json`（受保护路径，通用文件工具教学式报错）；旧时间线要素分类与目录零迁移整套退役。
- 事件分点事件与区间事件（区间两端标记一一配对，允许重叠与嵌套，时间轴贪心分轨）；时间三态——明确历法时间、相对时间（锚事件 + 偏移）、纯顺序（默认），系统永不按明确时间重排作者列表。
- 事件字段含参与者（四类要素 + 角色）、关联情节、章节关联（章号 + 叙述方式四值：当前线/回忆/预言/梦境，重号待消歧）、因果前驱；删除被引用要素自动清理参与者/情节引用，删除事件级联清除 causedBy 引用与以它为端点的关系，相对时间锚保留并进失效提示。
- 主智能体持六个时间线工具（List/Read/CreatePoint/CreateSpan/Update/Delete），确认卡与输入区接管按账本语义呈现（追加式账本不算「新建被占用」，删除只删一条事件不进回收站）。
- 关系账本支持事件端点（`kind: "event"` + EVT- 标识），用于「某事件导致某结果」因果边；事件删除时引用它的关系自动级联清理，关系画布以红色「事件」节点呈现。
- 界面：时间轴弹窗（自绘 SVG 单轴顺序、缩放 48–240px、搜索与形态/叙述/参与要素筛选、数据检查面板——账本 issue 隔离与清理、全量检查；损坏态只读 + 副本入回收站重新初始化）、详情编辑（两秒自动保存、冲突四出口、恢复镜像）、拖拽排序、新建表单；章节侧栏「本章相关事件」实时反查，点击定位到时间轴。
- 验收：契约测试 + OPFS 真机十项清单全过（真实模型全工具链、区间配对/重叠分轨、章节关联与重号消歧、级联四路、冲突/损坏出口、退役面、480/375 窄屏、200 标记性能目视）；200 标记下渲染秒级、无 JS 错误。

## 模型与外部资料

- 对话模型支持 OpenAI Chat Completions、OpenAI Responses、Anthropic 和 Gemini 协议。
- 流式正文、思考过程和工具调用统一进入 Agent 事件链。
- Embedding、Rerank 和输入补全独立配置。
- 支持联网搜索、网页阅读和知识平台条目查询，外部资料与本地文件写入分离。

## 主要界面能力

- 主工作区包含分类导航、对话面板和可编辑内容面板。
- 聊天展示流式回复、工具轨迹、写入确认和按文件聚合的差异。
- 输入框基于 Lexical，支持大纲引用、斜杠命令和可选的行内补全。
- 设置覆盖模型、检索、联网、权限、要素管理员和项目参数。
- 浏览器能力不满足要求时，首页直接显示环境阻塞原因。

## 需要持续观察

- 真实长篇项目中，要素摘要与整理质量能否支撑稳定、低成本的召回。
- 语义检索的触发时机、候选质量与重排效果。
- 上下文压缩后的剧情连贯性，以及长任务的停止、恢复和队列体验。
- 要素目录随项目规模增长后的上下文成本。
- 不同模型供应商和代理网关的协议兼容性。

上述观察不等同于已经排期的施工待办。确定要实施的改动应先形成具体计划。
