## 阻塞与风险

- 要素文件格式已具备第一版可写入结构，但提取协议仍需升级为 LLM 结构化输出
- 纯前端文件系统方案依赖浏览器能力，浏览器兼容性有限
- 写工具目前仍缺少 Claude Code 式权限确认机制，后续必须补齐
- 文件工具仍缺少写入前确认与 diff 预览，后续必须补齐
- Agent 当前对用户即时禁用工具、限制读取范围等约束遵守不稳定，可能在用户要求“不读文件”时继续调用读取工具
- `prompts/system.md` 只会在新建 Agent 消息上下文时注入；同一会话中编辑 system prompt 后，旧会话不会自动刷新为最新版
- `RagSearch` 已接入新的 Agent Loop，但模型是否稳定主动调用仍需要通过正式项目真实创作验证
- 当前向量召回仍是 IndexedDB 记录 + 手写 cosineSimilarity 的过渡实现，正式 Orama 召回链路待补齐
- 两阶段检索中的“Rerank 精排”效果需要在真实生成链路中继续验证
