## 项目与创作工作台

- 在浏览器中创建、打开、修复和恢复本地小说项目，查看最近项目与内容统计。
- 以项目文件保存章节、要素、提示词、大纲、创作计划和配置，支持预览、编辑和外部编辑器协作。
- 对话是 Agent 控制面，正文和设定不依赖聊天记录保存。
- 内容面板与文件树会响应 Agent 写入；删除文件先进入项目回收站。
- 支持写入确认、差异预览、运行停止、排队和插话，以及按会话查看文件变更。
- 创作计划板：计划目录中一张卡片一个 Markdown 文件，看板分收集箱、计划中、进行中、已完成四列，支持拖拽排序（三个看板共用一套落点反馈：拖起后源卡原位高度塌陷、按目标卡片垂直中心线判定落点并以等高占位卡预览，移开即收回、松手占位瞬间替换为真实卡片，插到列首走 beforeId、order 允许为负）、手动编辑正文与外部修改冲突提示；看板用于长期整理，不自动执行计划。布局与其他分类统一（见《计划页工作区布局统一计划》，已通过真机验收）：看板常驻中央主区域（白色体系），计划详情与新建共用右侧内容面板，进入计划默认收起、跨分类各自恢复；左侧计划标题行提供刷新入口，新建入口在侧栏「创作计划板」摘要卡下方（看板顶栏右端与其他页面统一为 GitHub 仓库与内容面板收起/展开开关）。详情默认 Markdown 预览（双击进入编辑、保存成功自动回预览）、计划名可直接修改且真实文件名同步（含新建文件名的可读计划名段）、保存与删除同列底部操作行；未保存草稿按卡片级编辑会话保留，切卡、收起面板、切换分类后重开同一卡片均可继续未保存内容和编辑模式；保存、读取、创建和看板刷新均按项目与卡片归属处理异步结果，快速切卡、保存中继续输入或切换项目时不会串稿、丢字或复活旧项目内容。
- 伏笔账本：`foreshadowing/` 目录一条伏笔一个 Markdown 文件，读者视角与作者真相分栏登记（真相只进规划链路，写正文读取永不含真相）；看板按六状态存储、默认四列视图（已埋/推进中/已收/已放弃，项目设置可切完整六列），卡片显示埋设章节与回收窗口、进入回收窗口且未收即「该收了」高亮；详情面板提供读者视角/作者真相双正文区、外部修改冲突检测与回收站删除；章节侧栏按选中章节实时反查「本章相关伏笔」（不写入章节文件）；主 Agent 写前调 ForeshadowingCheck、写后调 ForeshadowingSync 组装提案（含回收当量标准），提案经作者批准后逐条落盘。要素文件可在 frontmatter 用 `related_foreshadowing` 登记关联伏笔（要素↔伏笔双向链，要素管理员只保留不修改）。
- 节奏卡账本：`rhythm/` 目录一章一张卡片，frontmatter 登记计划值（冲突强度 1~10、情绪基调十选、章末钩子六选、爽点类型六选）与写后回写的实际值，正文记节奏意图与上下文衔接；主 Agent 通过五个基础工具（RhythmList/RhythmRead/RhythmCreate/RhythmUpdate/RhythmDelete）维护，回写实际值时系统自动判定偏差（冲突强度差 ≥ 项目阈值，默认 3，项目设置可调 1~10；情绪任一不符、钩子有↔无翻转、爽点任一不符）并流转状态（规划中/已写/偏差），状态与偏差标记不接受外部设置；正文更新带 contentHash 冲突检测，删除进回收站。看板三列固定（拖拽仅列内重排，跨列为无效落点：不显示占位、不可放），卡片带冲突强度三档着色与计划↔实际对比角标，看板带说明条提示「状态由回写自动判定、拖拽仅列内重排」；详情面板提供滑块/枚举下拉/实际值只读对比；章节侧栏按选中章节实时反查「本章节奏卡」（不写入章节文件）；主 Agent 写前调 RhythmCheck（含前后章概要）、写后调 RhythmSync 组装回写提案（与伏笔提案合并给作者审阅），RhythmCurve 提供章区间计划↔实际对照。
- 主智能体可在任务中途主动提问：结构化问题以独立卡片呈现（单选、多选、自由文本可并存），等待期间普通输入即作答，答案回灌后原任务继续；停止与刷新不遗留不可操作的等待。

## Agent 与上下文

- Agent Loop 参考 DeepSeek Harness，区分模型消息与聊天展示。
- 支持上下文压缩（达到阈值自动触发，也可用 /压缩上下文 斜杠命令随时手动触发）、分页读取、超长工具结果溢出保存与取回。
- 项目记忆和写作大纲按需进入模型视图，不自动注入近期章节。
- 章节、提示词、计划卡片和具体文件通过导航与读取工具按需获取；计划目录不进入语义索引。
- 文件查找按修改时间降序，超限结果跨顶层目录采样展示、完整列表存入溢出文件可取回；内容搜索默认字面匹配、带行号与上下文（正则可选、超限同样落溢出文件），查「人名/词语出现在哪些章节」用内容搜索，语义联想才走 RagSearch；内容搜索仅主智能体装配。
- EditFile 支持空文件以空旧文本直接填充；同一轮次连续编辑免重复读取，外部改动仍按修改时间与大小校验拦截（内容哈希兜底）。
- 主智能体可查询、读取、新建、修改和删除计划卡片，正文更新须先读后写防覆盖；要素管理员不持有计划工具。
- 写权限覆盖审阅、章节、素材、章节与素材、完全访问五档，内部目录另有硬保护。
- 内部文件（novel.config.json、.novel/、.novai/）对模型整体不可见：不出现在目录列表、文件查找与内容搜索中，读写指向时统一报教学式说明并引导改用上下文已有信息或直接询问用户；唯一例外是 .novel/spill/ 溢出取回通道（可读、可显式搜索，仍禁写）。
- 主动提问工具仅主智能体拥有（要素管理员直聊与委派不装配）；提问是只读交互，不进确认链与变更账本。

## 要素与多角色

- 主智能体负责创作、文件操作、外部资料查询和任务委派。
- 要素管理员维护人物、地点、实体、情节、时间线和世界观，支持直聊与独立委派会话。
- 委派会话保留完整工具过程、独立确认和变更记录，主会话接收结果汇报。
- 稳定要素先通过目录披露，再按名称批量加载完整内容。
- 情节和时间线通过语义检索召回，必要时可重排；章节不进入要素向量索引。
- 索引状态在工作区可见，用户可触发全量或指定来源的重建。

## 模型与外部资料

- 对话模型支持 OpenAI Chat Completions、OpenAI Responses、Anthropic 和 Gemini 协议。
- 流式正文、思考过程和工具调用统一进入 Agent 事件链。
- Embedding、Rerank 和输入补全独立配置。
- 支持联网搜索、网页阅读和知识平台条目查询，外部资料与本地文件写入分离。

## 主要界面能力

- 主工作区包含分类导航、对话面板和可编辑内容面板。
- 聊天展示流式回复、工具轨迹、写入确认和按文件聚合的差异。
- 输入框基于 Lexical，支持大纲引用、斜杠命令和可选的行内补全。
- 设置覆盖模型、检索、联网、权限、要素管理员和项目参数。
- 浏览器能力不满足要求时，首页直接显示环境阻塞原因。

## 需要持续观察

- 真实长篇项目中，要素摘要与整理质量能否支撑稳定、低成本的召回。
- 语义检索的触发时机、候选质量与重排效果。
- 上下文压缩后的剧情连贯性，以及长任务的停止、恢复和队列体验。
- 要素目录随项目规模增长后的上下文成本。
- 不同模型供应商和代理网关的协议兼容性。

上述观察不等同于已经排期的施工待办。确定要实施的改动应先形成具体计划。
