# NovAI 开发路线图

## Phase 0：基础搭建

目标：完成项目代码基础盘，建立后续开发骨架。

计划内容：

- 搭建 Vue + Vite 基础结构
- 引入路由、状态管理和基础样式方案
- 建立首页、工作区、设置页的页面骨架
- 明确核心目录结构

## Phase 1：项目与文件系统

目标：让用户能创建、打开并浏览一个小说项目。

计划内容：

- 接入项目创建流程
- 初始化标准项目目录结构
- 接入本地文件夹访问能力
- 实现文件树浏览与文件打开预览

## Phase 2：模型配置与生成链路

目标：打通“输入指令 -> 生成章节 -> 写入文件”的最小闭环。

计划内容：

- 配置 LLM 与 Embedding
- 实现 API 连通性测试
- 构建 AI 对话输入区域
- 支持流式生成与写入章节文件
- 支持右侧预览生成结果

## Phase 3：要素抽取与 RAG

目标：让生成结果可以沉淀为可检索上下文。

计划内容：

- 设计要素文件格式
- 从章节提取人物、地点、情节等要素
- 建立 Embedding 与 Orama 索引
- 打通粗检索链路
- 为后续 Rerank 精排预留结构

## Phase 3.5：创作结构优化

目标：让章节正文与要素结构更适合长期创作和持续检索。

计划内容：

- 将章节正文默认格式切换为 `txt`
- 新增 `elements/entities/`，用于武功、武器、坐骑、丹药、信物等具体实体
- 为 `characters / plots / timeline / entities` 建立更稳定的默认模板
- 调整 Agent 写章节、写要素和同步更新的默认规则
- 让文件树、预览和解析链路兼容新的内容组织方式

## Phase 4：上下文增强与稳定性

目标：提升长篇创作场景下的质量和可持续性。

计划内容：

- 补齐两阶段检索中的 Rerank 精排与高级审校
- 加入近期章节上下文拼装
- 完善错误处理与降级策略
- 优化生成中断、空结果、重试等边界情况

## Phase 5：辅助能力

目标：补齐工作台体验，提升实际可用性。

计划内容：

- Git 自动提交与历史查看
- 校对视图
- 章节整理视图
- 提示词调教工作流
- 设置页完善

## 当前建议优先级

当前代码已经越过 Phase 0 到 Phase 2 的基础验证，正式工作台、文件工具 Agent Loop、LLM 要素提取、过渡版 RAG 与 `RagSearch` 已经打通。**主工作区 UI 重构已全部完成（R1-R7 七个 Phase 全部落地）**：Activity Bar + 分类面板、设置模态框、内容面板三态 + 编辑模式、`@场景` 指令、选中内容引用、`/提取要素` 斜杠命令菜单、面板拖拽改宽，详见 [UI 重构计划](../plans/UI重构计划.md)。Agent 控制能力的「运行中停止」「结构化文件变更结果」「写入前确认 + diff 预览」已完成，其余控制项见 [Agent 控制能力补强计划](../plans/Agent控制能力补强计划.md)。当前建议聚焦：

1. Phase 3：验证要素抽取、索引重建、Agent 主动 RAG 检索在真实创作任务中的质量。
2. Phase 3.5：继续收敛 `chapters/*.txt`、`elements/entities/`、要素模板和 Agent 写入规则。
3. Phase 4：补齐写入确认、diff 预览、Query Guard/队列、近期章节上下文和错误降级。
4. Agent 控制能力补强计划的后续 Step（工具约束、system prompt 刷新）。

原因：

项目创建、文件操作、AI 工具调用链路和主工作台 UI（含对话驱动的指令体系）均已成立。下一步的关键是验证长篇创作质量、安全写入和上下文复用是否稳定，并补齐 Agent 控制能力的剩余环节。
